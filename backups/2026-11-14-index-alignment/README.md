# PALBALL

배경 #181818, 글자·로고 #ffffff. 장식 요소 없이 12열(모바일 4열) 그리드로 구성한 그래픽·편집디자인 스튜디오 아카이브입니다.

## 실행

상위 폴더의 `PALBALL.html`은 로고·스타일·스크립트가 모두 포함된 단일 HTML 파일입니다. 파일을 더블클릭하면 서버나 인터넷 연결 없이 실행됩니다. 이메일과 인스타그램 링크는 해당 외부 서비스로 연결됩니다. 소스를 수정한 뒤 `python3 tools/export_html.py`를 실행하면 단일 파일을 다시 생성합니다.

`dist/index.html`을 브라우저로 열면 동작합니다. 로컬 서버로 보려면 이 폴더에서 `python3 -m http.server 8000 --directory dist`를 실행하고 `http://localhost:8000`에 접속하세요. 라이브러리 설치나 빌드는 필요 없습니다.

## 화면 이동

홈에는 로고 인터랙션만 표시하며 스크롤로 다른 화면에 이어지지 않습니다. 헤더의 WORKS는 작업 목록, ABOUT은 소개와 하단 연락처를 표시합니다. PALBALL 로고를 누르면 홈으로 돌아갑니다. 단일 파일에서도 독립 주소 `#home`, `#works`, `#about`으로 이동하며 브라우저 뒤로/앞으로 가기와 해당 화면에서 새로고침을 지원합니다. 기존 `#work`, `#studio`, `#contact`, `#top` 링크도 새 화면으로 연결됩니다. 작업 상세도 같은 문서 스크롤을 사용합니다. 상세를 닫거나 Esc를 누르면 기존 WORKS의 검색·필터·보기 방식과 스크롤 위치로 돌아가고 상세의 PALBALL 로고는 홈으로 이동합니다.

## 작업 추가

`dist/projects.js`의 `window.PALBALL_PROJECTS` 배열에 작업 객체를 추가하세요. 필수 항목은 `id`, `title`, `category` (`graphic` 또는 `editorial`), `discipline`, `type`, `description`입니다. 여러 분야에 속하면 `categories` 배열을 지정하세요. `images` 배열의 각 항목에는 `src`, `alt`를 지정합니다. 기존 캡션 데이터는 보존하지만 상세 화면에는 표시하지 않습니다. 이미지는 `dist/assets/`에 넣으세요. 작업 목록, 필터별 개수, 갤러리와 상세 페이지가 자동으로 갱신됩니다.

현재는 BLOC! 폰트 카탈로그(PDF 9페이지), 「바다를 건넌 보부상들」(이미지 8장), PALBALL 아이덴티티까지 총 3건이 등록되어 있습니다. 보부상들은 제공된 설명에 따라 가상 전시의 워크숍 결과물로 표시하며 디자인 원채영, 멘토 임민재 크레딧을 포함했습니다. `works/` 원본은 수정하지 않았고 웹용 사본과 썸네일은 `dist/assets/works/`에 저장했습니다. PDF는 PNG로 변환하며 단일 HTML에도 전부 포함합니다. BLOC! 변환본은 가장자리의 밝은 선을 제거하기 위해 사방 2px를 잘랐고, 썸네일도 잘린 이미지로 다시 생성합니다. 원본 PDF는 보존합니다. 해당 설정은 `pdfCropPixels: 2`로 저장되어 다시 가져와도 유지됩니다.

## works 자동 추가

`works/프로젝트 이름/` 안에 설명 HTML(또는 TXT/MD)과 JPG, PNG, WebP, TIFF, SVG, PDF를 넣으세요. 감시 프로그램이 파일 복사가 끝날 때까지 기다린 뒤 새 작업과 변경된 설명을 HTML에 반영합니다. PDF는 모든 페이지를 가져옵니다. 브라우저는 새로고침하면 새 작업이 보입니다.

현재는 Codex 작업 세션의 감시 프로그램을 사용합니다. macOS가 로그인 자동 실행 프로그램의 Desktop 접근을 차단해 해당 로그인 항목은 중지했습니다. Mac이나 Codex를 재시작한 뒤에는 상위 폴더의 `자동 추가 시작.command`를 더블클릭해 감시를 다시 켜세요. 같은 감시 프로그램이 이미 실행 중이면 중복 실행하지 않습니다. 감시를 실행한 터미널을 닫거나 Ctrl+C를 누르면 종료됩니다.

설명의 첫 문장은 부제, 나머지 문장은 본문으로 사용합니다. `디자인: 이름`, `멘토: 이름`, 판형 정보도 인식합니다. 폴더 이름이 작업 제목이고 분야는 설명의 키워드로 분류합니다. 정확하게 지정하려면 같은 폴더의 선택적 `project.json`에 `title`, `subtitle`, `description`, `categories`, `discipline`, `type`, `credits`, `imageOrder`를 넣을 수 있습니다. 기존 등록 작업은 폴더를 지워도 자동 삭제하지 않습니다.

한 번 가져오기: `python3 -B tools/sync_works.py`

현재 창에서 감시: `python3 -B tools/sync_works.py --watch`

로그인 시 자동 실행 설치 도구도 포함되어 있습니다. 이 방식은 macOS에서 해당 프로그램의 Desktop 접근을 허용한 경우에만 동작합니다: `python3 -B tools/install_works_watch.py`

로그인 항목 상태 확인: `python3 -B tools/install_works_watch.py --status`

로그인 항목 감시 중지: `python3 -B tools/install_works_watch.py --stop`

자동 갱신은 `PALBALL.html`의 작업 데이터만 교체해 직접 고친 CSS·본문·인터랙션을 보존합니다. 소스의 CSS나 JS를 수정한 경우에는 `python3 -B tools/export_html.py`로 전체 HTML을 다시 만드세요. 상태와 로그는 프로젝트 최상위 `.works-sync/`에 있습니다.

## 아카이브 인터랙션

WORKS는 큰 도입 제목 없이 검색·필터 다음에 작업물을 바로 보여주고 갤러리 모드로 시작합니다. SEARCH에 작업 이름을 입력하면 즉시 검색하며, 영문 대소문자를 구분하지 않고 여러 검색어도 사용할 수 있습니다. 분야 필터와 함께 동작하고 결과가 없으면 안내와 전체 작업 복원 버튼을 보여줍니다. 보기 전환은 GALLERY, INDEX 순서이고 헤더 WORKS 옆의 작업 개수는 표시하지 않습니다. 헤더는 배경 없이 화면 위에 고정되며 PALBALL은 공통 헤더와 상세 헤더 모두 데스크톱 40px, 모바일 32px입니다. 헤더 설명과 상세 헤더의 분야는 제거했습니다. 헤더 글자 형태에만 배경 반전 필터를 적용해 어두운 배경 위에서는 흰색, 밝은 배경 위에서는 #181818로 표시합니다. 컬러 이미지도 글자 안에서 두 색으로 변환하며 1px 밑줄과 키보드 포커스·메뉴 링크는 유지합니다.

모든 밑줄 두께는 CSS 기준 1px입니다. 작업 제목은 호버 시 이동하지 않고 밑줄과 화살표가 나타납니다. 인덱스와 갤러리 모두 작업 번호를 표시하지 않습니다. 인덱스의 PROJECT / DISCIPLINE / TYPE 헤더는 표시하지 않습니다. 인덱스에서 작업을 호버하거나 키보드로 포커스하면 해당 썸네일을 12열 그리드의 네 번째 컬럼 왼쪽에 맞춰 글자 뒤에 띄웁니다. 미리보기는 포인터 입력을 가로채지 않으며 호버·포커스가 끝나면 숨깁니다. 갤러리는 고정 2단 그리드 대신 이미지 비율에 맞춘 가변 폭으로 배치하며, 썸네일 높이는 최대 560px 안에서 현재 화면 높이에 맞춰 줄어듭니다. 검색·필터 영역과 프로젝트 제목·분야·타입의 실제 높이, 행 간격을 측정해 첫 줄의 썸네일과 정보를 보여주면서 다음 줄 이미지의 윗부분이 최대 96px 드러나도록 높이를 줄입니다. 화면 크기나 검색·필터가 바뀌면 다시 계산합니다. 제목·분야·타입은 이미지 바로 아래 왼쪽에 정렬합니다. 작업 상세의 분야와 타입은 각각 한 줄로 배치하며 이미지 아래의 캡션은 모두 표시하지 않습니다. `scrollbar-gutter: stable`로 문서의 스크롤바 공간을 확보하고 상세도 같은 문서 스크롤을 사용해, 홈·WORKS·ABOUT·상세에서 스크롤바 위치와 가로 정렬을 유지합니다. 상세에는 별도 스크롤 컨테이너를 만들지 않습니다.

## 로고

폴더의 원본 SVG는 수정하지 않았습니다. 사이트에 사용하는 사본은 흰색으로 변환했습니다. 두 로고는 공통 배율을 사용하며, PAL은 크기와 x좌표를 유지한 채 수직 이동한 뒤 가로로 정렬됩니다. 오른쪽 원은 정방향에서 첫 구간의 크기를 유지하고 가로 정렬 중 커집니다. 역방향에서는 가로 이동 중 큰 상태를 유지하다가 PAL의 하강과 함께 작아집니다. 방향을 전환하다 다시 클릭해도 현재 원 크기에서 이어지며, 원의 아래쪽은 프레임 하단에 항상 맞춰집니다. 클릭과 키보드 Enter/Space로 전환할 수 있으며, 동작 줄이기 설정에서는 즉시 바뀝니다.

28px 마우스 커서는 흰 원 하나에 `mix-blend-mode: difference`를 적용합니다. 썸네일과 상세 이미지의 컬러도 직접 반전하며 이미지 밝기를 샘플링하거나 흰색·#181818 두 색으로 제한하지 않습니다. 상세 화면에도 같은 커서를 유지하며 터치 환경에서는 표시하지 않습니다.

## 내용

소개글과 연락처는 제공된 내용을 사용했습니다. 컨택의 `PALLBALL` 표기도 원문 그대로 유지했습니다. `dist/index.html`에서 수정할 수 있습니다.
